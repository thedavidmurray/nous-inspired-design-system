Texture Pipeline

Pipeline Modes

Eight rendering modes that map any source image onto the Edgeless visual language. Each uses real dithering algorithms, not AI approximations.

dither-bw Floyd-Steinberg
1-bit black/white Floyd-Steinberg error diffusion. The closest to the original IMG_8154 dot-matrix aesthetic. Every pixel is either on or off — no grey.
--mode dither-bw
dither-accent Bayer 8x8
Ordered Bayer matrix dither to void + one accent color. Produces the classic cross-hatch pattern. Accent selectable: cyan, violet, indigo, green, white.
--mode dither-accent --accent cyan
dither-full 5-Color FS
Floyd-Steinberg error diffusion to the full 5-color Edgeless palette (void, indigo, violet, cyan, white). Rich color with structural texture.
--mode dither-full
riso Halftone Dot
Risograph print simulation. Halftone dot screen on cream (#f5f0e8) paper base with two ink separations: black + accent. Rotated screen angles prevent moire.
--mode riso --accent cyan
scanline CRT Sim
CRT/VHS monitor simulation. Scanline darkening every 3rd row, 5-bit color quantization, horizontal glitch offsets. Retro terminal aesthetic.
--mode scanline
thermal Receipt
Thermal receipt printer. Sigmoid contrast crush + 1-bit dither + horizontal banding artifacts + thermal head smear blur. Black ink on white paper.
--mode thermal
riso-violet Halftone Dot
Same risograph engine as riso-cyan but with violet (#8b5cf6) ink separation. Use for warmer, more editorial print feel.
--mode riso --accent violet
dither-accent-violet Bayer 8x8
Ordered dither to void + violet. Same structured pattern as cyan accent but with the secondary brand color.
--mode dither-accent --accent violet
