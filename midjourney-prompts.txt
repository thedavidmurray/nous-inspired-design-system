# POST-PROCESSING CHEAT SHEET
#
# After downloading MJ outputs, run:
#
# Single image:
#   python3.11 scripts/edgeless-texture-pipeline.py image.png --mode dither-bw -o out.png
#   python3.11 scripts/edgeless-texture-pipeline.py image.png --mode thermal -o out.png
#   python3.11 scripts/edgeless-texture-pipeline.py image.png --mode riso --accent cyan -o out.png
#   python3.11 scripts/edgeless-texture-pipeline.py image.png --mode dither-accent --accent violet -o out.png
#
# Batch (whole directory):
#   python3.11 scripts/edgeless-texture-pipeline.py --batch mj-outputs/ --mode dither-bw --output-dir processed/
#
# Recommended combos:
#   Environments (01-07, 09-12) → dither-bw or thermal
#   Diagrams/Infographics (03, 13) → dither-accent --accent cyan
#   Print/Editorial (14-16, 18, 20) → riso --accent violet
#   Texture studies (13, 17) → dither-full (keeps all accent colors)
#   Product shots (08) → dither-accent --accent cyan
#   Retro/CRT (19) → scanline
