Pipeline
OUTPUT 004 / SEED: 1192837465 / CLASS: PIPELINE_DEMO

One Source, Six Outputs

The same generated image run through all six modifications. AI cannot produce real structural dithering natively — smooth gradients and soft noise are not Floyd-Steinberg error diffusion or ordered Bayer matrices. The pipeline is deterministic: same input + same seed = same output.

riso-cyan Halftone on cream
scanline CRT simulation
dither-accent Bayer 8x8 violet
thermal Receipt printer
