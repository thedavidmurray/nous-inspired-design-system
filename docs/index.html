Philosophy

Two-Stage Pipeline

AI generates composition, color, and mood. Then deterministic dithering post-processes every pixel into a structural pattern. AI cannot produce real structural dithering natively -- smooth gradients and soft noise are not the same as Floyd-Steinberg error diffusion or ordered Bayer matrices where every pixel participates in the pattern. The pipeline exists to bridge this gap.

Quickstart

Get Started

Three paths depending on what you need. All paths get you the full Nous aesthetic.

Developer

React components + Tailwind preset. Drop in and build.

pnpm add @edgelesslab/design-system
import { Button, Card, Badge } from '@edgelesslab/design-system';

Designer

CSS custom properties. Drop tokens.css into any project.

<!-- Drop-in token file --> <link rel="stylesheet" href="tokens.css">
background: var(--color-accent-primary);

Content Creator

300 prompts + texture pipeline. Generate and process.

# Pick a prompt, generate, then post-process: python3.11 scripts/edgeless-texture-pipeline.py \ input.png --mode dither-bw -o output.png
