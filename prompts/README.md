# Edgeless Lab Prompt Library

Organized by category. All prompts designed for the texture pipeline post-processing workflow.

## Workflow
1. Generate with recommended model (MJ, Flora, Venice)
2. Post-process: `python3.11 scripts/edgeless-texture-pipeline.py output.png --mode <mode> -o processed.png`
3. Recommended pipeline mode listed per prompt

## Categories
- `environments.txt` — Spaces, architecture, interiors
- `diagrams.txt` — Technical, network, data visualization
- `editorial.txt` — Print, zine, catalog, typography
- `textures.txt` — Patterns, gradients, material studies
- `cosmic.txt` — Space, orbital, signals, transmissions
- `artifacts.txt` — Devices, objects, relics, shrines
- `archive.txt` — Memory, decay, deprecated, archaeological
- `ui-screens.txt` — Terminal, dashboard, interface mockups
