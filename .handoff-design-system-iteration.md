## YOUR TASKS

### PHASE 1: Score Everything (1-2 hours)
1. Write `.prompt.txt` sidecars for ALL 27 files in `public/generated examples/`
   - Derive prompt content from the filename (they contain the generation prompt)
   - Ensure each sidecar includes: exact hex codes, `courier`/`monospace`, `edgeless`, `dark`, `minimal`, `high contrast`, `brutalist`, `swarm`
   - One sidecar per image (not per variation — if multiple variations of same prompt exist, write one sidecar and symlink or duplicate)

2. Run the eval on the entire design system:
   ```bash
   cd ~/claude-projects/edgelesslab-design-system
   python scripts/design-alignment-eval.py --all > eval-report-generated.txt
   ```

3. Extract the `generated examples/` section and report scores

### PHASE 2: Compare & Curate (1 hour)
4. Compare generated example scores against:
   - `public/originals/` (baseline: physical artifacts, target S-grade)
   - `public/courier/` (current best generated assets)
   - `public/flora-v2/` (AI-generated production assets)

5. Identify:
   - **KEEP**: Generated examples that score ≥ A-grade (0.80+) — these are better than existing assets
   - **REPLACE**: Existing courier assets that are outperformed by generated examples
   - **ITERATE**: Generated examples that score < B-grade (0.70-) — these need prompt refinement
   - **DELETE**: Duplicates or clearly worse variations

### PHASE 3: Prompt Refinement (2-3 hours)
6. For each low-scoring generated example, identify WHY it scored low:
   - Missing hex codes? → Add exact tokens to prompt
   - Missing typography? → Add `Courier monospace` or `JetBrains Mono`
   - Missing aesthetic terms? → Add `minimal dark high contrast brutalist geometric`
   - Missing brand? → Add `Edgeless swarm signal agent`

7. Write refined prompts in `universe-build-prompts-v2.txt` with:
   - Problem diagnosis (why original failed)
   - Refined prompt with fixes applied
   - Target model recommendation (which Flora model handles this prompt type best)
   - Expected score after fix

### PHASE 4: Regenerate & Verify (2-3 hours)
8. Queue regeneration of the worst 5-10 generated examples via Flora:
   - Use refined prompts from Phase 3
   - Target models: Flux 2 Pro (atmospheric), Recraft V4 Pro (UI/vector), Ideogram 3.0 (text-heavy), Nano Banana Pro (fidelity)
   - Download outputs to `public/generated examples/v2/`

9. Write sidecars for new outputs and re-run eval

10. Report final delta: before vs after scores
